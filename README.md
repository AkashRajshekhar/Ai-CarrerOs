# AI CareerOS 🚀

AI CareerOS is an AI-powered career guidance platform built using the **MERN Stack**. It helps students analyze resumes, discover career paths, identify skill gaps, and prepare for jobs and interviews.

## ✨ Features

- 🔐 JWT-based Authentication
- 📄 AI Resume Analyzer
- 🎯 AI Career Recommendations
- 📊 Skill Gap Analysis
- 🗺️ Personalized Learning Roadmap
- 💼 AI Job Matching
- 🎤 AI Interview Preparation
- 🤖 AI Career Assistant
- 📈 Career Progress Dashboard

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, Tailwind CSS

**Backend:** Node.js, Express.js

**Database:** MongoDB, Mongoose

**AI Integration:** LLM API

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/AkashRajshekhar/Ai-CarrerOs.git
cd Ai-CarrerOs
```

### 2. Backend Setup

```bash
cd server
npm install
```

Create a `.env` file inside the `server` directory:

```env
PORT=5000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
AI_API_KEY=your_ai_api_key
AI_API_URL=your_ai_api_url
```

Start the backend:

```bash
npm run dev
```

### 3. Frontend Setup

Open a new terminal:

```bash
cd client
npm install
npm run dev
```
