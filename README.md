# AI CareerOS 🚀

AI CareerOS is an AI-powered career guidance platform built with the **MERN stack**. It helps students analyze resumes, discover career paths, identify skill gaps, and prepare for jobs and interviews.

## ✨ Features

* AI Resume Analyzer
* Career Recommendations
* Skill Gap Analysis
* Personalized Roadmap
* AI Job Matching
* Interview Preparation
* AI Career Assistant
* Career Dashboard

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, Tailwind CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose
**AI:** LLM API

## 🚀 Clone & Run

```bash
git clone https://github.com/AkashRajshekhar/ai-careeros.git
cd ai-careeros
```

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

Open a new terminal:

```bash
cd client
npm install
npm run dev
```

Create a `.env` file inside `server`:

```env
PORT=5000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
AI_API_KEY=your_ai_api_key
AI_API_URL=your_ai_api_url
```
